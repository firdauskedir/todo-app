# To-Do List App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript. The application allows users to manage their daily tasks through CRUD operations, with JSON Server used as the backend.

## Features

* Add new tasks
* View all tasks
* Edit existing tasks
* Delete tasks
* Manage tasks using JSON Server

## Technologies Used

* HTML5
* CSS3
* JavaScript
* JSON Server

## Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install JSON Server if needed:

   ```bash
   npm install -g json-server
   ```

4. Start JSON Server:

   ```bash
   json-server --watch db.json
   ```

5. Open `index.html` in your browser.
